# Week 7 Task 2: JWT Authentication System

## Project Description
A full-stack authentication application using React and Node.js.

## Technologies Used
- React
- Vite
- Node.js
- Express.js
- Axios
- React Router
- JSON Web Token (JWT)
- bcrypt

## Features
- User registration
- User login
- Password hashing
- JWT token authentication
- Protected dashboard
- Login and logout functionality
- Axios authorization interceptor

## How to Run

### Backend
1. Open the server folder.
2. Install dependencies using `npm install`.
3. Create a `.env` file with `PORT=5000` and a `JWT_SECRET`.
4. Start the backend using `node server.js`.

### Frontend
1. Open the client folder.
2. Install dependencies using `npm install`.
3. Start the frontend using `npm run dev`.
4. Open `http://localhost:5173`.

## Note
This demonstration stores registered users temporarily in memory.
User data is lost when the backend restarts.
